# Features Implemented

MemoMeet includes the core features needed to capture meeting context, store it as memory, and use it for better preparation.

## Meeting Memory

- Add meeting notes, transcripts, or summaries.
- Extract useful information from meeting content.
- Store memories across multiple meetings.
- Preserve context for future discussions.

## AI Memory Extraction

- Identify key decisions.
- Extract action items.
- Track commitments.
- Detect participant preferences.
- Capture important discussion topics.
- Find useful follow-up points.

## Participant Tracking

- Link memories to participants.
- Track participant-specific commitments.
- Remember preferences and important context.
- Support more personalized follow-ups.

## Smart Retrieval

- Rank memories by importance.
- Rank memories by recency.
- Retrieve relevant memories before future meetings.
- Prioritize pending commitments and useful context.

## Meeting Preparation Briefs

- Generate AI-powered preparation reports.
- Show previous meeting highlights.
- Surface pending action items.
- Suggest follow-up questions.
- Provide important talking points.
- Help users prepare with less manual effort.

## Dashboard

- View meeting information.
- Review extracted memories.
- Track action items.
- See participant-related context.
- Access insights for better meeting continuity.
