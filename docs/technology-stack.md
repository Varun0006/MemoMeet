# Technology Stack Used

MemoMeet uses a practical web application stack for building, storing, and displaying meeting memory.

## Backend

- Python
- Flask
- SQLAlchemy

## Frontend

- HTML
- CSS
- JavaScript
- Jinja2 templates

## Database

- SQLite or local database configuration
- Structured storage for meetings, memories, participants, and action items

## AI Layer

- AI/LLM integration for memory extraction
- AI-generated meeting preparation briefs
- Context-aware follow-up suggestions

## Configuration

- Environment variables
- `.env` file for local configuration
- `.env.example` as a reference for required settings

## Development Tools

- Git
- GitHub
- Python virtual environment or UV for dependency management
