# Solution Overview

MemoMeet is an AI-powered Meeting Preparation Agent that turns meeting history into actionable memory.

After a meeting, the user can add meeting notes, transcripts, or summaries. MemoMeet analyzes this content and extracts the most important details, such as:

- Key decisions
- Action items
- Commitments
- Participant preferences
- Important discussion topics
- Follow-up points

These extracted details are stored as structured memories and linked to the relevant meetings and participants.

Before a future meeting, MemoMeet retrieves the most useful memories based on importance, recency, participant relevance, and pending status. It then generates a meeting preparation brief that helps the user walk into the next discussion with the right context.

The preparation brief can include:

- Previous meeting highlights
- Pending commitments
- Suggested follow-up questions
- Important talking points
- Participant-specific insights

MemoMeet is different from a basic meeting summarizer because it does not treat each meeting as a separate event. It remembers useful context across multiple meetings and uses that memory to improve future conversations.

The goal is simple:

Help every meeting start with context instead of starting from zero.
